# Nova-AI
A lightweight AI chatbot web app, designed for fast responses and simple deployment.
# Features
- Fast AI responses using Groq API (LLaMA / Mixtral models)
- Real-time chat streaming
- Conversation memory (session + local JSON storage)
- Modern dark UI with custom chat styling
- Export chat as TXT file
- Export chat as PDF file
- Clear chat history option
- Sidebar with model selection + recent history
- Rate limiting to prevent spam requests
